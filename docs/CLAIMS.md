# Claims and evidence

Every claim Secret Shopper makes, the command that checks it, and where the evidence is. Contract tests run with `cd contracts/shop && cargo test <name>` after building both wasm files (see [AGENTS.md](../AGENTS.md)). Backend and agent tests run with `bun test` in their directory. Testnet links open on testnet.nearblocks.io; the same data is available from the public RPC.

Verified on 2026-11-12 (`bun run verify`, 12 of 12 steps): 18 unit tests, 35 sandbox tests, 4 audit regression tests and 1 cost test pass (`cargo test -- --test-threads=4`); `cargo clippy --all-targets -- -D warnings` and `cargo fmt --check` clean; backend 277 pass, 27 skip (294 pass, 0 fail with Postgres and network gates open); agent 108 pass; `bun run demo` exits 0 with 33 checks; `scripts/mcp-e2e.ts` holds 46 checks; `bun scripts/global-vault.ts` passes.
